# Gentle retro menu source drafts (2026-10-03)

These six preserved source drafts followed the user's preference for soft pixel
texture and faded earth colors. After reviewing this direction, the user asked
for regular geometric shapes that can scroll. This set is therefore **not the
final adopted direction**; the next calibration sample lives in `../Pattern-v4`.
The legacy and Multiverse-v2 sources remain intact.

Each theme used one built-in ImageGen call. All six files are 941×1672 RGB PNGs
and byte-identical copies of their generated originals. The exact submitted
prompts are `{theme}-prompt.txt`; `source-manifest.json` records original paths,
SHA-256, dimensions and references. Red had no supplied image references. Each
other color used only Red as its primary reference, with no login or v2 reference.
The actual `Before/Runtime/375x667/red-home.png` screenshot was inspected solely
for placement of the character, white UI and controls.

The drafts use quiet slate, faint worn paper/pixel dither, and small amounts of
washed side color: brick red, sage/moss, denim/indigo, beige/ochre-grey,
aubergine/plum, or cool neutral grey. The center and edges remain restrained;
there are no UI, characters, text, large stones or action marks. Their irregular
paint-like color fields did not fulfill the user's later regular-pattern request.

`previews/{theme}.png` are 360×640 sips downscales for review. Source visual QA
confirmed the six themes share the same soft treatment. This agent did not edit
Assets or scenes, run Unity, or validate seamless scrolling or actual UI behavior.
